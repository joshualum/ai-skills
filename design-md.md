# Design System Generator

Extract color tokens, typography rules, layout spacing, and UI principles from screenshots or brand descriptions. Output a clean `design.md` file with:
- **Design Principles:** 3–4 core visual rules (e.g., "Quiet interface", "Content-first").
- **Color Palette:** CSS variable definitions for primary, surface, border, and text tokens.
- **Typography & Layout:** Font families, scale, and grid padding rules.
